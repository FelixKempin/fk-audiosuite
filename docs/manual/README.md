# FK Audio Suite – User Manual

This manual explains every feature of FK Audio Suite step by step, with screenshots. It grows with the application: each chapter is updated together with the code it describes.

Maintainers: see [MAINTAINING.md](MAINTAINING.md).

## Conventions

- **Bold** marks things you see on screen: buttons, menus, list entries, keys.
- **View › Key Editor** means: open the **View** menu, choose **Key Editor**.
- Numbers in screenshots (orange circles) match the numbered table or steps next to the picture.
- Shortcuts are the defaults. You can change them in **Edit › Keyboard shortcuts…**; the manual always names the default.
